# Loopr MongoDB Integration

This is the database integration milestone for the Loopr Financial Dashboard.

## Data flow

transactions.json
    -> seed.ts
    -> MongoDB Atlas
    -> Express API
    -> React frontend

The React application does not read transactions.json at runtime and does not connect directly to MongoDB.

## Setup

1. Copy `backend/.env.example` to `backend/.env`.
2. Replace `MONGODB_URI` with the connection string generated by MongoDB Atlas.
3. From `backend/`, install dependencies:

   npm install

4. Seed the dataset:

   npm run seed

5. Start the API:

   npm run dev

6. Test:

   GET http://localhost:5000/api/health
   GET http://localhost:5000/api/transactions

The supplied dataset contains 300 transaction records. The seed script replaces the existing transaction collection contents so repeated development seeding does not create duplicates.

## Important

Never commit `backend/.env` or expose the MongoDB password in source code, screenshots, README files, or GitHub.
